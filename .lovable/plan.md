## Obiettivo
Creare una cartella `/docs` alla radice del progetto che raccolga la documentazione di riferimento.

## Operazioni

1. **Spostare `design-system.md`** dalla radice a `docs/design-system.md` (via `mv`).
2. **Spostare `README.md`** dalla radice a `docs/README.md` (via `mv`).
3. **Creare `docs/Context.md`** con il contenuto integrale del file allegato `Contesto_App_Studentato_Europa.md` (273 righe), copiato verbatim.

## Note
- Nessuna modifica al codice sorgente o alla build: sono solo file `.md` di documentazione, non referenziati da import.
- Il nuovo `Context.md` mantiene il nome richiesto (maiuscolo iniziale) anche se gli altri due file restano con la loro capitalizzazione originale.
